# Fonts for marketing art

`Roboto-Black.ttf` and `Roboto-Bold.ttf` are Roboto by Christian Robertson (Google), licensed under the
Apache License 2.0 (free for commercial use, including rasterized store graphics). They are only used by
`Tools/marketing/make_store_art.py`; the game itself uses Unity's default UI font.

Thai and Vietnamese captions use the same Roboto files (Latin + Vietnamese diacritics); for Thai the script
falls back to a system font that covers the script (Leelawadee UI / Tahoma on Windows).
